# 数据库文档简介

### 部门(sys_department)

| 字段       | 描述       | 类型   | 备注                             |
| ---------- | ---------- | ------ | -------------------------------- |
| id         | 部门主键   | long   |                                  |
| pid        | 上级部门   | long   | 可以是公司或者部门ID。值来源id列 |
| name       | 部门名称   | string | 最大长度： 200,                  |
| is_company | 是否是公司 | bool   | 0：部门，1：是公司。默认0        |
| state      | 状态       | int    | 0:显示，1：不显示，3：删除       |

### 角色( sys_role)

| 字段  | 描述     | 类型   | 备注            |
| ----- | -------- | ------ | --------------- |
| id    | 角色主键 | long   |                 |
| Name  | 角色名称 | string | 最大长度：50    |
| desc  | 角色描述 | string | 最大长度：500   |
|       |          |        |                 |
| state | 状态     | int    | 0:启用，1：禁用 |

### 用户( sys_user)

| 字段    | 描述               | 类型   | 备注                                  |
| ------- | ------------------ | ------ | ------------------------------------- |
| id      | 用户主键           | long   |                                       |
| name    | 用户显示名称       | string | 最大长度：50                          |
| account | 账号登录的时候使用 | string | 最大长度：50.可以和name一样。唯一索引 |
| pwd     | 密码               | string | 最大长度：100 。加密存储              |
| slot    | 加盐字符串         | string | 用来和密码加解密                      |
| dept_id | 部门id             | long   | 外键来源于部门表                      |
| state   | 状态               | int    | 0:启用，1：禁用                       |
|         |                    |        |                                       |



### 角色菜单权限( sys_menu_function)

| 字段    | 描述                    | 类型 | 备注 |
| ------- | ----------------------- | ---- | ---- |
| id      | 菜单权限ID, 主键        | long |      |
| menu_id | 菜单id.唯一标识某个菜单 | int  |      |
|         |                         |      |      |
|         |                         |      |      |
|         |                         |      |      |



### 知识分类(sys_knowledge_category)

| 字段 | 描述              | 类型   | 备注         |
| ---- | ----------------- | ------ | ------------ |
| id   | 字段主键id        | long   |              |
| name | 类别名称          | string | 最大长度：50 |
| pid  | 它的上级,值来源id | long   |              |
|      |                   |        |              |
|      |                   |        |              |

### 知识库基础信息(knowledge_base)

| 字段           | 描述                                  | 类型     | 备注                    |
| -------------- | ------------------------------------- | -------- | ----------------------- |
| id             | 知识组件                              | long     |                         |
| file_name      | 知识库文件名称                        | string   | 最大长度：500           |
| md5            | 摘要信息，用来校验文件唯一型          | string   | 最大长度：200。唯一索引 |
| file_path      | 文件路径，用来加载文件，需要考虑minio | string   | 最大长度：800           |
| create_date    | 创建时间                              | datetime | 创建时间                |
| update_date    | 修改时间                              | datetime | 修改时间                |
| create_user_id | 创建人                                | long     | 来源用户表              |
|                |                                       |          |                         |
|                |                                       |          |                         |
