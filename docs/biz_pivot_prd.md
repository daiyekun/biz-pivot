## 1\. 项目概述

### 1\.1 产品名称

商枢 BizPivot —— 企业私有智能AI平台

### 1\.2 产品定位

面向企业内部私有化部署的**权限可控、数据隔离、安全合规**的企业AI智能平台。

集成：AI智能闲聊、企业私有RAG知识库问答、角色分级文档权限、企业智能可视化报表、报表导出、企业人员/部门/角色完整后台管理体系。

核心主打：**企业知识可控、数据严格隔离、权限分级授权、禁止外部随意上传文档**。

### 1\.3 文档目的

本文档用于明确「商枢 BizPivot 企业智能AI平台」整体业务需求、功能模块、权限规则、数据隔离机制、交互规范及非功能需求。作为项目开发、测试、迭代、交付的唯一标准依据，统一团队认知，避免需求偏差。

### 1\.4 用户角色总览（新增完整后台角色体系）

- **超级管理员（系统内置、唯一、不可删除）**：拥有系统最高所有权限，初始化内置账号，无需手动创建

- **授权文档管理员角色**：由超级管理员授权，拥有知识库文档上传、分类管理权限

- **普通企业员工**：仅AI闲聊、仅检索自己角色授权的知识库、仅查看自己权限内报表

### 1\.5 完整核心能力清单（最终定稿）

1. 全局登录鉴权，未登录禁止使用所有功能

2. 通用AI智能闲聊、多轮对话、上下文智能压缩

3. **多模型提供商配置能力：后台可配置多个模型提供商（name/endpoint/model/api_key），聊天角色可绑定指定提供商**

4. **智能聊天角色体系：支持自定义聊天角色（系统提示词/温度/绑定提供商），每个会话必须选择一个聊天角色，系统发起聊天由程序直接指定内置角色（意图识别/语义识别等）**

5. 企业私有RAG知识库问答能力

6. **完整企业后台体系：超级管理员、员工账号管理、部门管理、角色管理、角色授权、知识库分类管理、模型提供商、聊天角色管理**

7. **严格知识库权限体系：文档按上传时设置的五级数据权限（个人/部门/公司/部门及子部门/跨部门）精准隔离，跨部门精准权限隔离**

8. **文档上传权限锁死：不对外开放，仅授权角色可上传**

9. 企业智能数据可视化报表、AI数据分析、报表解读

10. 数据报表文件导出功能

11. 员工账号启用/禁用管理能力

## 2\. 系统权限架构（核心企业级RBAC体系）

### 2\.1 账号体系规则

1. **系统内置超级管理员账号**

   - 系统初始化自动生成，**唯一、固定、不可删除、不可禁用**

   - 拥有系统**全部最高权限**

   - 负责：创建部门、创建角色、创建员工账号、分配权限、禁用员工、授权文档上传权限

2. 所有普通员工账号**必须由超级管理员后台创建**，用户自主无法注册

3. 超级管理员可随时**禁用/启用**任意员工账号，禁用后无法登录系统

### 2\.2 部门体系

- 支持企业多级部门创建、编辑、删除

- **部门采用无限级树形结构**，支持任意层级嵌套

- 所有员工必须归属指定部门

- 部门为辅助维度，同时参与知识库数据权限（部门/部门及子部门/跨部门权限判定）

### 2\.3 角色体系（核心权限控制）

- 超级管理员可自定义创建任意角色

- 权限颗粒度区分：**功能权限 \+ 数据权限**

**功能权限**：是否可进入后台、是否可上传文档、是否可管理分类

**数据权限**：可查看/检索哪些知识库文档、可查看哪些报表数据

## 4\. 知识库权限核心规则（最终定稿、严格管控）

### 4\.1 文档上传权限管控（强约束）

**后台知识库上传功能完全不对外开放**，严格禁止普通员工随意上传文档。

上传权限规则：

1. 默认所有普通角色**无任何文档上传权限**

2. 仅超级管理员**手动授权指定角色**，才可拥有【文档上传、文档管理、分类管理】权限

3. 未授权角色：前端隐藏上传入口、后端直接拦截上传接口，返回无权限

### 4\.2 知识库文档五级数据权限体系（V1.1 核心更新）

每一篇上传的知识库文档，**在上传时必须独立设置一个数据权限**，选项如下：

| 权限类型 | 设置方式 | 可见/可检索范围 |
| -------- | -------- | --------------- |
| **个人** | 无需选择，默认为上传者本人 | 仅上传者本人可以检索、查看、问答该文档；其他任何人（同部门/其他部门）均不可见 |
| **部门** | 手动选择一个指定部门 | 仅该部门直属人员可检索该文档；子部门、其他部门不可见 |
| **公司** | 选择所属公司主体 | 该公司下所有部门、所有员工均可检索该文档 |
| **部门及子部门** | 手动选择一个指定部门 | 当前部门 + 该部门所有下级子部门全员均可检索该文档 |
| **跨部门** | 手动多选多个不同部门 | 被选中的所有部门全员均可检索该文档，适用于跨部门协作、共享资料场景 |

**权限规则约束：**

1. 每一篇文档独立设置权限，不同文档可配置不同可见范围

2. 权限一旦设定，实时生效；RAG检索时后端自动过滤无权限文档

3. 用户提问RAG检索时，后端自动过滤向量数据：

   - 只召回当前用户**有权访问**的文档片段（依据五级权限判定）

   - 无权限文档彻底屏蔽，不参与Prompt、不展示、不泄露

4. 权限判定优先级：先判定文档上传者（个人文档仅本人可见）→ 再按部门/公司/跨部门范围判定

### 4\.3 跨部门知识检索能力（精准实现）

通过「五级权限中的部门及子部门 / 跨部门」实现可控跨部门知识共享：

1. 文档设置为【跨部门】并选择多个部门，被选部门员工即可跨部门检索、问答该文档

2. 文档设置为【部门及子部门】，部门下所有层级员工可见

3. 未授权部门严格隔离，保证企业私密资料安全

**总结：部门做组织归属，文档上传时设置数据权限，灵活实现隔离与共享。**

## 5\. 完整模块功能需求（已全部更新新版权限逻辑）

### 5\.1 登录与全局鉴权模块

- 未登录用户禁止所有功能，自动跳转登录页

- 支持超级管理员、员工账号统一登录入口

- 禁用账号无法登录，提示账号已被禁用

- 全局Token鉴权、会话Redis存储、分布式无状态

### 5\.2 超级管理员后台管理模块（V1.1 细化）

#### 5\.2\.1 部门管理

**页面入口**：左侧菜单【部门管理】

**页面结构**：**无限级树形结构**（支持无限层级部门嵌套），树形不启用分页；节点数据量大时可扩展子节点懒加载

**工具栏操作**：新增、修改、删除

**业务规则**：

- 新增部门：选择父级部门（根部门可不选），填写部门名称、排序、备注

- 修改部门：编辑部门基础信息，支持更换父级部门（注意防止循环嵌套）

- 删除部门：删除前做关联校验，存在下级子部门或归属用户时禁止删除，需先处理子部门/迁移用户

#### 5\.2\.2 用户管理

**页面入口**：左侧菜单【用户管理】

**页面结构**：用户列表页面，**表格分页展示**

**工具栏操作**：新增、修改、删除

**业务规则**：

- **新增用户时必须选择一个归属部门（部门为必选项）**

- 支持编辑用户基础信息、所属部门、绑定角色

- 支持删除用户（删除前校验关联数据）

- 支持按用户名、部门筛选，筛选后重置分页至第一页

#### 5\.2\.3 角色管理

**页面入口**：左侧菜单【角色管理】

**页面结构**：角色列表页面，**表格分页展示**

**工具栏操作**：新增、修改、删除

**业务规则**：

- 自定义创建角色，支持填写角色名称、角色描述、启用/禁用状态

- 修改角色基础信息

- 删除角色前校验是否存在用户绑定，存在绑定则禁止删除

#### 5\.2\.4 角色授权

**页面入口**：左侧菜单【角色授权】

**页面结构**：上方角色选择（列表分页） + 下方授权区域

**核心能力**：系统菜单权限 + 知识库权限 双重授权

**业务流程**：

1. 页面上方选择/搜索指定角色（角色列表分页展示）

2. 展示**系统菜单权限树**：树形勾选该角色可见/可操作的菜单（如用户管理、部门管理、角色管理、角色授权、知识库分类、知识库上传），勾选后角色对应菜单即对角色成员可见可用（菜单树不分页）

3. 展示**知识库权限配置**：为角色分配知识库上传/管理权限，以及可访问的知识库分类范围

**最终效果**：角色权限控制分为两层：

- UI层：控制菜单是否可见

- 接口层：后端拦截无权限接口请求

#### 5\.2\.5 知识库分类管理

**页面入口**：后台菜单【知识库分类】

**页面结构**：**无限级树形分类结构**（支持无限层级知识库分类嵌套），树形不启用分页；节点数据量大时可扩展子节点懒加载

**工具栏操作**：新增、修改、删除

**业务规则**：

- 新增分类：选择父级分类，填写分类名称

- 修改分类：编辑分类名称、排序

- 删除分类：删除前校验是否存在下级分类或已关联知识库文档，存在则禁止删除

- 所有上传的知识库文档必须归属某一分类

#### 5\.2\.6 模型提供商（V1.2 新增）

**页面入口**：后台菜单【模型提供商】

**页面结构**：模型提供商列表页面，**表格分页展示**

**核心能力**：可配置**多个模型提供商**，供聊天角色、AI 闲聊、RAG 问答、智能报表等选择调用。

**工具栏操作**：新增、修改、删除

**字段说明**：

| 字段 | 类型 | 描述 | 备注 |
| ---- | ---- | ---- | ---- |
| name | string | 提供商名称 | 最大长度 100，唯一 |
| endpoint | string | API调用地址 | 最大长度 255 |
| model | string | 模型名称 | 最大长度 100 |
| api_key | string | API密钥 | 加密/保密展示 |

**业务规则**：

- 支持配置多个提供商（如 OpenAI / 通义千问 / 私有化部署模型），互不影响

- 新增/修改/删除提供商；删除前校验是否被聊天角色引用，被引用则禁止删除

- API 密钥为敏感信息，列表展示脱敏（掩码）

#### 5\.2\.7 智能聊天角色（V1.2 新增）

**页面入口**：后台菜单【聊天角色】

**页面结构**：聊天角色列表页面，**表格分页展示**

**核心能力**：自定义聊天角色，为每个角色设定**系统提示词、模型温度、绑定模型提供商**。

**工具栏操作**：新增、修改、删除

**字段说明**：

| 字段 | 类型 | 描述 | 备注 |
| ---- | ---- | ---- | ---- |
| name | string | 角色名称 | 最大长度 100，唯一 |
| description | string | 角色描述 | 最大长度 200 |
| system_prompt | string | 系统提示词 | 最大长度 4000 |
| temperature | float | 模型温度 | 默认 0.7 |
| provider_id | long | 模型提供商ID | 外键→sys_provider |

**业务规则**：

- 每个聊天角色可绑定一个模型提供商（provider_id），也可暂不绑定（使用默认提供商）

- **系统内置角色**（启动自动初始化）：通用助手、意图识别、语义识别；系统发起聊天（意图识别、语义识别等）由程序直接指定这些内置角色

- 删除聊天角色前校验是否被会话引用，被引用则禁止删除

### 5\.3 AI闲聊对话模块

- 所有登录员工、管理员均可使用

- 多会话管理、流式输出、上下文智能压缩

- **会话关联聊天角色（V1.2 强约束）**：**每个会话必须选择一个聊天角色，只有选择聊天角色后才能创建会话**；会话通过外键 `chat_role_id` 关联 `sys_chat_role`

- **消息角色枚举（V1.2）**：聊天消息记录角色类型，枚举取值——系统消息 / 用户消息 / 助手消息 / 工具消息（0=系统 1=用户 2=助手 3=工具）

- 独立于知识库权限，全员通用

### 5\.4 企业RAG知识库模块（权限重写完毕）

#### 5\.4\.1 知识库上传

**页面入口**：左侧菜单【知识库上传】

**页面结构**：知识库文档列表页面，**表格分页展示**

**工具栏操作**：新增上传、删除（**不提供修改功能**）

**数据可见范围**：超级管理员可查看所有人上传的知识库文档（其他角色按五级权限过滤）

**上传必填信息**：

- 知识库名称（必填）

- 知识库描述（必填）

- 归属知识库分类（必填）

- 文档数据权限（必填，五选一）：个人 / 部门 / 公司 / 部门及子部门 / 跨部门（详细见 4.2 五级数据权限体系）

**文档上传与解析**：

- **仅超级管理员授权角色可上传**

- 支持 PDF / MD / TXT 企业文档

- Celery异步解析、切片、向量化入库

- 上传完成后，RAG检索实时依据文档数据权限过滤

**功能限制**：

- 知识库文档**不支持修改**，仅支持上传和删除

- 权限一旦设定实时生效，RAG检索时自动过滤无权限文档

- 权限粒度：单文档独立权限，不同文档可配置不同可见范围

#### 5\.4\.2 智能问答权限逻辑

- 对话页可开关知识库问答

- 开启后，后端根据**当前用户身份 + 文档五级数据权限**过滤全部知识库数据

- 精准实现：有权限则检索回答，无权限完全隔离

- 支持跨部门知识共享（依靠部门/部门及子部门/跨部门权限）

### 5\.5 智能数据报表模块

- 自然语言数据分析、AI自动解读、可视化图表展示

- 支持报表数据导出文件（落地汇报、存档）

- 报表数据跟随用户角色/部门做数据隔离，员工只能看自己权限数据

## 6\. 列表分页通用规范（V1.1 新增）

> 规则：**表格列表启用分页；无限级树形页面（部门管理、知识库分类）不做分页，一次性加载整棵树，节点量大可后续扩展子节点懒加载。**

适用模块：用户管理、角色管理、角色授权（角色选择列表）、知识库上传（文档列表）。

### 6\.1 分页入参约定

- `pageNum`：页码，默认第1页

- `pageSize`：每页条数，默认10条；下拉选项：10 / 20 / 50 / 100

- 后端强制限制最大 `pageSize = 100`，禁止前端传入超大值一次性拉取全表，防止数据库压力

### 6\.2 返回数据结构

```json
{
  "records": [],  // 当前页数据列表
  "total": 0,     // 总数据条数
  "pages": 0      // 总页数
}
```

### 6\.3 前端交互规则

- 列表底部展示分页组件：上一页、页码、下一页、支持直接跳页

- 列表执行搜索/筛选条件变更时，页码自动重置到第1页

- 删除操作成功，刷新列表保持当前页码；新增成功，列表刷新回到第1页

### 6\.4 后端规则

- 所有表格列表接口必须分页查询，禁止一次性查询全表

- 分页查询时自动带入当前登录用户身份，同步完成功能权限、数据权限过滤

## 7\. 核心权限业务流程图（文字版）

### 7\.1 系统初始化流程

1. 系统部署启动 → 自动创建内置超级管理员账号

2. 系统初始化自动生成后台菜单（部门管理、用户管理、角色管理、角色授权、知识库分类、知识库上传、模型提供商、聊天角色）

3. 系统初始化自动创建默认模型提供商（来源于 .env LLM 配置）与系统内置聊天角色（通用助手/意图识别/语义识别）

4. 超级管理员登录 → 创建企业部门架构（无限级树形）

5. 创建业务角色、配置角色权限（菜单授权：是否可见；功能授权：是否可上传文档）

6. 创建员工账号、分配部门\+角色

7. 创建知识库分类树，上传知识库文档并设置五级数据权限，完成数据权限配置

### 7\.2 用户问答权限校验流程

1. 用户登录 → 携带用户ID、角色列表、部门信息

2. 发起知识库问答

3. 后端根据用户身份 + 文档五级数据权限（个人/部门/公司/部门及子部门/跨部门）筛选**权限内的知识库文档向量**

4. 仅使用授权文档片段生成答案

5. 无权限数据完全隔离，保证企业数据安全

### 7\.3 文档上传权限校验流程

1. 用户点击上传文档

2. 后端校验当前用户角色是否拥有【文档上传权限】

3. 无权限：直接拦截，前端隐藏入口

4. 有权限：允许上传，填写知识库名称、描述、归属分类，并设置文档五级数据权限

### 7\.4 角色授权流程

1. 超级管理员进入【角色授权】

2. 选择目标角色

3. 勾选该角色可见/可操作的菜单（菜单权限树）

4. 配置该角色的知识库上传/管理权限及可访问分类

5. 保存后即时生效：角色成员重新登录或刷新后按新权限展示菜单、调用接口

## 8\. 非功能需求

### 8\.1 安全需求（重点强化）

- 严格的RBAC双层权限：**功能权限 \+ 数据权限**

- 知识库不对外开放上传，杜绝员工随意上传机密文件

- 文档五级数据权限强隔离（个人/部门/公司/部门及子部门/跨部门），防止企业资料泄露

- 禁用账号彻底失效，无法访问任何资源

### 8\.2 体验需求

- 权限不足时友好提示，不空白、不报错

- 异步任务进度可视化

- AI流式输出、状态提示，优化慢推理体验

- 无限级树形页面提供展开/折叠、搜索定位能力

### 8\.3 架构需求

- 服务无状态、Redis外置会话，支持分布式多实例部署

- 分层架构清晰，可平滑微服务拆分

- 权限逻辑统一在后端校验，前端仅做展示隐藏（防绕过）
