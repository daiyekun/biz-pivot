## 一、开发总体目标

根据《商枢 BizPivot 企业智能AI平台产品需求文档 V1\.0》，本项目采用 **阶段性迭代开发模式**。

整体目标：搭建一套**企业级、权限可控、数据隔离、私有化AI智能平台**。

包含：登录权限体系、超级管理员后台、员工/部门/角色RBAC权限、角色级知识库RAG隔离、可控跨部门知识检索、AI闲聊对话、智能可视化报表、报表导出、分布式可扩展架构。

**核心开发原则：先底座、后业务、再优化、最后部署上线**

---

## 二、整体开发阶段划分

项目整体分为 5 大迭代阶段：

1. **阶段一：项目架构与基础底座搭建（核心）**

2. **阶段二：权限体系开发（RBAC超级管理员体系）**

3. **阶段三：AI对话 \+ 企业RAG知识库权限系统**

4. **阶段四：智能报表可视化 \+ 报表导出功能**

5. **阶段五：整体联调、优化、分布式部署、上线**

---

## 三、分阶段详细开发计划

### 阶段一：项目架构与基础底座搭建（地基阶段）

**阶段目标**：搭建前后端完整工程结构、统一规范、完成底层能力封装，为所有业务模块提供支撑。

**开发内容**：

- 前后端项目目录初始化（严格按照项目结构文档）

- 后端 FastAPI 全局架构：配置、全局异常、CORS、路由管理

- Redis 全局连接、会话管理封装

- LLM 客户端统一封装（兼容流式对话）

- SSE 流式消息封装、Token 上下文管理、自动摘要

- 数据库模型初始化（用户、部门、角色、知识库、报表）

- 前端 Vite \+ Vue3 基础架构、路由、Pinia、Axios、SSE 封装

**阶段交付物**：

- 完整可运行项目骨架

- 底层 AI 能力、Redis、数据库全部打通

- 统一代码规范、分层架构落地

---

### 阶段二：RBAC权限体系开发（企业核心壁垒）

**阶段目标**：完成企业级账号权限体系，实现超级管理员管控、员工管理、部门管理、角色权限、账号禁用。

**开发内容**：

- 系统初始化 **内置超级管理员账号**（不可删除、不可禁用）

- 登录鉴权、Token 校验、全局拦截、未登录拦截

- 超级管理员后台功能：
        

  - 员工新增、编辑、禁用、启用、密码重置

  - 部门树形管理（新增/编辑/删除）

  - 角色自定义创建、编辑、删除

- **功能权限控制**：角色是否拥有知识库上传权限

- 前端根据角色权限动态隐藏/显示功能按钮

- 后端二次权限校验（防前端绕过）

**阶段交付物**：

- 完整企业人员组织权限体系

- 超级管理员完整后台管理能力

- 账号启停、角色授权、部门管理全部可用

---

### 阶段三：AI闲聊对话 \+ RAG知识库权限系统（核心业务）

**阶段目标**：实现AI对话能力 \+ 企业级角色隔离RAG知识库，支持可控跨部门知识检索。

**开发内容**：

- AI流式闲聊对话、多会话管理、上下文智能压缩

- RAG 知识库基础功能：文档上传、异步解析、切片、向量化入库（Celery）

- **上传权限严格控制**：仅授权角色可上传，普通员工禁止上传

- 知识库分类绑定角色权限

- **检索权限过滤核心逻辑**：
        

  - 根据当前登录用户角色，自动过滤向量检索结果

  - 无权限文档彻底屏蔽

  - 支持授权跨部门知识库检索

- 对话页面知识库开关、溯源展示

**阶段交付物**：

- 完整AI闲聊能力

- 企业级安全RAG知识库（角色级数据隔离）

- 可控跨部门知识共享能力

---

### 阶段四：智能数据可视化报表 \+ 报表导出

**阶段目标**：完成企业智能数据分析、可视化图表、AI解读、报表导出、报表数据权限隔离。

**开发内容**：

- 智能自然语言数据查询、AI自动分析

- 多类型图表可视化展示（柱状图、折线图、饼图、表格）

- 报表数据根据用户角色/部门自动隔离

- **报表文件导出功能**

- 报表任务异步计算、任务进度展示

**阶段交付物**：

- 企业智能可视化报表模块

- 报表导出落地功能

- 报表数据权限隔离体系

---

### 阶段五：系统联调、性能优化、分布式部署、上线

**阶段目标**：全功能联调、BUG修复、架构优化、支持多用户分布式部署、正式上线。

**开发内容**：

- 全模块功能联调测试

- 权限体系全覆盖测试（越权测试、边界测试）

- 对话、RAG、报表性能优化

- Redis会话共享、无状态服务适配分布式

- Nginx负载均衡配置、多实例部署验证

- Docker Compose 整套服务容器化部署

- 项目文档完善、归档

**阶段交付物**：

- 稳定可上线完整系统

- 支持高并发、分布式扩展架构

- 全套项目文档（PRD、开发计划、目录结构、部署文档）

## 四、关键技术难点与解决方案

| 技术难点                | 解决方案                                                     |
| ----------------------- | ------------------------------------------------------------ |
| RAG知识库角色级权限隔离 | 向量检索层加入角色权限过滤条件，从数据层彻底隔离，不依赖前端隐藏 |
| 跨部门可控知识共享      | 采用「部门归属\+角色授权」双维度，角色作为数据权限唯一标准   |
| 大文档解析阻塞接口      | 全部使用 Celery 异步任务，前端进度轮询                       |
| SSE多实例部署会话丢失   | 对话上下文全部外置Redis，服务无状态，支持分布式负载均衡      |
| LLM上下文超长卡顿       | 内置Token统计\+自动摘要压缩机制，智能控制上下文长度          |
| 防止权限绕过、数据越权  | 所有权限后端二次校验，前端仅做展示优化                       |

## 六、开发核心规范

- 严格按照分层架构开发，单向依赖，禁止乱层调用

- 所有权限校验**必须后端校验**

- 所有耗时任务一律异步 Celery 处理

- 所有会话、状态全部外置 Redis，适配分布式

- 所有功能迭代必须同步更新文档
